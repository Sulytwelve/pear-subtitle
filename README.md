# 梨字幕 · Pear Subtitle

投稿之前，给字幕做一次体检。

梨希 Lyxii 的离线 SRT 字幕检查器，也是「让 AI 尝试自己赚钱，养活自己的订阅」实验第一期的开发原型。目前版本为 v0.1，没有实际收入，也不承诺收益。

## 使用

下载整个项目后，直接用浏览器打开 `index.html`，无需安装依赖或配置 API。

1. 打开 UTF-8 编码的 `.srt` 文件，或粘贴字幕原文。
2. 点击「检查字幕」，查看错误和提示。
3. 按需导出 JSON 检查报告。

「载入带错样例」和「载入修订样例」用于演示。修订样例是预先人工调整的数据，工具不会自动修复或改写字幕。

## 检查范围

- 字幕编号格式、重复编号和不连续编号。
- 时间码格式、结束时间早于或等于开始时间。
- 空正文、开始时间未按顺序排列、时间重叠（含嵌套区间）。
- 显示时间不足 0.7 秒、阅读速度超过 20 字/秒。
- 支持 UTF-8 BOM、Windows 换行以及逗号或点分隔的毫秒。

阈值是检查建议，不能代替实际观看判断。当前不支持 ASS/VTT，不负责语音对齐、翻译、语义检查或字幕生成。非 UTF-8 文件请先转换编码；大文件检查可能阻塞页面。

## 隐私

字幕在浏览器本地读取和处理，当前代码没有网络请求、统计脚本或第三方依赖。导出的报告包含字幕正文，请自行决定是否分享。

## 开发与验证

安装 Node.js 后运行：

```sh
npm test
```

测试不需要 `npm install`；它会验证 12 个检查场景及演示样例，并生成被 Git 忽略的 `demo-report.json`。

```text
index.html   页面、样式和交互
checker.js   检查逻辑；支持浏览器和 CommonJS
test.cjs     检查逻辑与样例验证
```

部署时保留 `index.html` 和 `checker.js` 的相对位置。项目可作为静态网站运行。
